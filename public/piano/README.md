# Piano samples

From the **Salamander Grand Piano V3** by Alexander Holm (Yamaha C5), licensed
[CC-BY 3.0](https://creativecommons.org/licenses/by/3.0/). Fetched from the copies
hosted by Tone.js (`https://tonejs.github.io/audio/salamander/`).

Modified: trimmed to the first 3 s with a 0.8 s fade-out, mixed to mono, re-encoded at 64 kbps.
One sample every minor third (C, D♯, F♯, A) from A1 to C7.
